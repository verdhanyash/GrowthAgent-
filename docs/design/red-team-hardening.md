## Adopted mechanisms (the deltas that matter)

1. **Velocity TOCTOU closure** (TB-2/TB-2b, CRITICAL): atomic Redis-Lua checkAndRecord BEFORE evaluation (gatekeeper.md §14.1) + identity_velocity ledger re-verified inside the reservation transaction (settlement.md). N racing approvals cannot jointly exceed a limit where money commits.
2. **Claim-first order creation** (TB-13): ORDER_CREATING CAS state elected sole creator before any network call (settlement.md T4a/T4b).
3. **Provider boot assertions + stamped-provider refusal** (TB-7/TB-7b): explicit RAZORPAY_PROVIDER enum, refuse-boot on placeholder/mismatch, provider_kind stamped into genesis/orders, PAID refused on mismatch (ARCHITECTURE.md §6.6, settlement.md).
4. **Transports-not-validators replay barrier** (TB-8/DR-4): stable mode never relaxes validation; recorded webhooks replay as raw signed bytes through the same HMAC path; fixture manifest pins sha256; paced replays; runtime mode switch; ARM_FOR_NEXT_TX chaos semantics (ARCHITECTURE.md §13).
5. **Citation auditor relation checks** (TB-9): Stage 1b STOCK_OVERDRAW + Stage 2b PRIORITY_REF_MISMATCH added as fatal codes (negotiation.md §4.2).
6. **Overall pipeline deadline → guaranteed gated FALLBACK** (DR-1b): orchestrator wall-clock budget spanning pack→negotiation→auditor (ARCHITECTURE.md §12).
7. **Secret-redaction chokepoint + timing-safe agent-key compare** (TB-14) and **prompt-cache policy** (DR-14: TTL choice, warm-up constraints, cache_read observability) (ARCHITECTURE.md §10/§6.2).
8. **Broken-chain quarantine rendering** (TB-12), **rules-increase cool-down + RULES_UPDATED payload** (TB-11), **normative demo-reset enumeration** (DR-3) (api-contract.md, data-model-audit.md).
9. **Untrusted-text chassis + narration constraint** (TB-5), **rAF burst smoothing + memoized rule rows** (DR-15), **demo-reset UI affordance + LIVE twin label** (DR-3b/DR-4b) (frontend-events.md).
10. **PrioritySet blast-radius relabeling** (TB-15: ADVISORY CONTEXT ONLY) and **pack-build source rollup policy** (DR-2) (negotiation.md).
